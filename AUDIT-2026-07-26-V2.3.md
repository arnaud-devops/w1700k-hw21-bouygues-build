## Accepted limits

The forced hash makes official `kmod-*` packages installable but does not prove
ABI compatibility with this patched kernel. The exact public kmods snapshot
can disappear, and this release does not publish a permanent custom package
repository. Use only reviewed, targeted APK transactions and never a bulk
`apk upgrade`.

The public Attended Sysupgrade service cannot reproduce this custom source,
patch and recovery set. The supported update path remains a checksum-verified
local sysupgrade.

## Remaining hardware gate

This proves image structure, provenance and contents, not runtime behavior.
The active router still runs the validated Gilly 17.07 image. A separately
authorized hardware test must cover boot and rollback, RTL8261CE binding, WAN
10G, multigig LAN2, sustained IPv4/IPv6 PPE traffic, all three APs, DoQ,
Watchcat, ttyd, SFTP, pstore and irqbalance before v2.3 can be recommended as
stable.
